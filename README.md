# RP Proto

RobotPilots 通用协议仓库.

本仓库仅存储`protobuf`协议定义, 以及`protobuf`工具链, ci配置等等, 不存储任何语言绑定的封装代码.

## 协议结构

Git Tag 用于规定已发行的协议版本, 格式为: `v` `[赛季]` `[主版本]` `[修订版本]`. 比如 `v27.1.0`.

目前协议主要分为这些种类:

| 简称(包名) | 含义 |
| -------- | ---- |
| Common | 通用消息定义, 不会直接用于传输 |
| ... | 待定 |

## 环境和工具链

目前主要使用这些工具:

- `protoc`: protobuf基本工具
- `buf`: 提供批量代码生成和lint
- [ ] `nanopb`: c语言绑定生成. 目前暂未实装.

项目有配好`nix`, 可以使用`nix`进入开发环境.

```bash
# 方法A: 使用direnv
direnv allow

# 方法B: 直接使用nix
nix develop
```

## CI

目前包含这些自动化:

1. 每次推送, 自动进行`lint`

2. [ ] 进行自动生成并推送到发布分支
