# RP Proto

RobotPilots 通用协议仓库.

本仓库仅存储`protobuf`协议定义, 以及`protobuf`工具链, ci配置等等, 不存储任何语言绑定的封装代码.

## 协议结构

### 版本定义
Git Tag 用于规定已发行的协议版本, 格式为: `v` `[赛季]` `[主版本]` `[修订版本]`. 比如 `v27.1.0`.

所有`修订版本`会向后兼容, 而`主版本`常常为破坏性变更.

对接使用请务必使用已发布版本. 未发布的分支通常会有不兼容的变更.

### 包定义

| 包 | 含义 |
| -------- | ---- |
| common | 通用类型定义 |
| control | 机器人控制命令 |
| game | 比赛相关信息 |
| module | 机器人功能模块 |
| spatial | 空间和运动相关 |
| toplevel | 顶层通信消息 |

## 环境和工具链

目前主要使用这些工具:

- `protoc`: protobuf基本工具
- `buf`: 提供批量代码生成和lint
- [ ] `nanopb`: c语言绑定生成. 目前暂未实装.

项目有配好`nix`, 可以使用`nix`进入开发环境.

```bash
# 方法A: 使用direnv
direnv allow

# 方法B: 直接使用nix
nix develop
```
